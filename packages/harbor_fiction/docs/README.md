# Harbor Fiction Registry

Fictional fixture package for Open Matchday teams registry tests and demos.

- All clubs and players are invented.
- Do not treat names as real organizations or people (PROJECT_SPEC AC-9.7).
- Adult sample photos are generated 1x1 PNGs with explicit attribution; minors have no photos (AC-9.3).
- Consent evidence is never stored in this repository.

## Lineup fixtures (OM-029)

Foxes senior squad includes five starters and two substitutes with basketball position ids. Owls futsal squad includes a goalkeeper and four outfield starters plus one substitute. Use sports package formation `position_id` values when binding lineups.
